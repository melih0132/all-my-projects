# Flutter Projects

This folder contains my Flutter development projects, covering a wide range of cross-platform mobile applications. These projects demonstrate my proficiency in Flutter, Dart programming, and various mobile development technologies.

## Projects Included

### 1. [Namer App](namer_app)
A basic introduction to Flutter, demonstrating the fundamentals of building cross-platform mobile applications.

- State management with Provider
- Basic UI components
- Navigation between screens

**Technologies**: Flutter, Dart, Provider

### 2. [Weather App](weather_app)
An application connecting to the OpenWeatherMap API to display weather information based on location or search.

- Real-time weather data
- Location-based weather
- Search functionality
- Weather forecasts

**Technologies**: Flutter, Dart, HTTP, Geolocation

### 3. [Event Poll](event_poll)
An application allowing administrators to manage events and users to register and indicate their presence at events.

- User authentication
- Event creation and management
- Poll creation and voting
- Real-time updates

**Technologies**: Flutter, Dart, Firebase, Provider

## Technologies Used

### Languages & Frameworks
- **Dart**: Primary programming language

### State Management
- **Provider**: State management solution

### Backend Services
- **Firebase**: Backend-as-a-Service platform

### Development Tools
- **Visual Studio Code**: Primary IDE
- **Flutter SDK**: Development toolkit
- **Git / GitHub**: Version control
- **Android Studio**: Android development environment
