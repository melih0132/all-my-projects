# Flutter Projects

Cross-platform mobile apps built with Flutter and Dart.

## Overview

Introductory and course apps covering state, networking, and Firebase-backed events.

## Stack

- Flutter, Dart
- Provider
- HTTP, geolocation
- Firebase (event_poll)

## Layout

```
flutter/
├── event_poll/
├── namer_app/
└── weather_app/
```

## Run

Open a child app folder, run `flutter pub get`, then `flutter run`.
