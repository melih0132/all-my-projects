# Mobile

Cross-platform and native mobile coursework.

## Overview

Flutter, Kotlin/Compose, and Swift/UIKit apps grouped under one mobile area.

## Stack

- Flutter, Dart
- Kotlin, Jetpack Compose
- Swift, UIKit

## Layout

```
mobile/
├── flutter/
├── kotlin/
└── swift/
```

## Run

Open a child platform folder and follow its README.
