# Kotlin Projects

Android apps built with Kotlin and Jetpack Compose.

## Overview

Material 3 samples covering state, lists, input, and simple animations.

## Stack

- Kotlin
- Jetpack Compose
- Material Design 3
- Gradle

## Layout

```
kotlin/
├── Affirmations/
├── DiceRoller/
├── HappyBirthday/
├── Lemonade/
├── TipTime/
└── Woof/
```

## Run

Open a child project in Android Studio and run on an emulator or device.
