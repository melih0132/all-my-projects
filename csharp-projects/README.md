# C# Projects

.NET desktop, API, and Unity work.

## Overview

WPF apps with and without databases, modern ASP.NET / WinUI samples, and Unity games.

## Stack

- C#, .NET, ASP.NET Core, Entity Framework
- WPF, WinUI 3
- PostgreSQL
- Unity

## Layout

```
csharp-projects/
├── csharp-with-db/       → DB-backed WPF (dortan-app)
├── csharp-without-db/    → Console and WPF (evit-shuriken)
├── net-core-projects/    → REST APIs, WinUI, converters
└── unity/                → KUBE
```

## Run

Open a child folder and follow its README.
