# DortanApp

WPF reservation manager for municipal activities.

## Overview

Create or select activities, book date ranges, and filter records. UI binds to PostgreSQL; early UX was drafted in Figma.

## Features

- Activity CRUD
- Reservation date entry
- Record filtering
- PostgreSQL persistence
- WPF data binding

## Stack

- C#, WPF, XAML
- PostgreSQL, SQL, pgAdmin4
- Figma, Visual Studio

## Layout

```
dortan-app/
└── Dortan_IHM/
```

## Run

```bash
cd csharp-projects/csharp-with-db/dortan-app
```

Open the solution in Visual Studio, configure the PostgreSQL connection, then run the WPF project.
