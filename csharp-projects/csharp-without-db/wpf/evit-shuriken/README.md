# Evit Shuriken

First-year WPF action game built with C# and XAML.

## Overview

Dodge projectiles, react quickly, and move between menu and game-over screens with basic visual and audio feedback.

## Features

- Character movement
- Projectile collisions
- Menu and game-over flows
- UI effects and sounds

## Stack

- C#, WPF, XAML
- Visual Studio
- Git

## Layout

```
evit-shuriken/
├── MainWindow.xaml
├── EntreeEnJeu.xaml
└── NinjaJeu.sln
```

## Run

```bash
cd csharp-projects/csharp-without-db/wpf/evit-shuriken
```

Open `NinjaJeu.sln` in Visual Studio and run.
