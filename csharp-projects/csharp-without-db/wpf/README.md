# WPF Projects

This folder contains projects developed using Windows Presentation Foundation (WPF). These projects focus on creating rich user interfaces and demonstrating various features of WPF, including layout management, data binding, and event handling.

## Projects Included

### 1. [EVIT_SHURIKEN](EVIT_SHURIKEN)
A WPF game application that challenges players to navigate through various levels while avoiding obstacles.

- Engaging gameplay with increasing difficulty
- Interactive user interface designed with XAML
- Smooth graphics and animations
- Score tracking and level progression

**Technologies**: C#, WPF, XAML

## Technologies Used

### Languages & Frameworks
- **C#**: Primary programming language
- **WPF**: Windows Presentation Foundation framework
- **XAML**: Markup language for UI design

### UI Features
- User-friendly interfaces with XAML
- Data binding for dynamic content display
- Event-driven programming with user interactions
- Custom controls and user controls
- Styling and templating for a polished look
- Responsive design for various screen sizes
- Storyboard animations for UI elements
- Graphics rendering with shapes and paths
- Interactive elements with visual feedback

### Development Tools
- **Visual Studio**: Primary IDE
- **Git / GitHub**: Version control

## Getting Started

Each project has its own README with detailed instructions. To explore a project:

1. Navigate to the project directory
2. Read the project's README.md for specific setup instructions
3. Follow the installation and configuration steps
4. Run the project according to its documentation

### Prerequisites

- Visual Studio (latest version recommended)
- .NET SDK
- Git

### Quick Start

1. Open Visual Studio
2. Open the solution file (`.sln`) in the project directory
3. Restore NuGet packages if needed
4. Build the solution
5. Run the application (F5)

Feel free to explore the repositories for more detailed information on each project!
