# KUBE

3D platformer built with Unity and C#.

## Overview

Level navigation, collisions, death animation, and a main menu. Used to practice Unity editor workflows, physics, and simple game UX.

## Features

- 3D platforming and physics
- Level progression
- Death animation and menu
- Particle and sound cues

## Stack

- Unity, C#
- Visual Studio
- Git

## Layout

```
KUBE/
├── Apprentissage/     → Unity project
└── README.md
```

## Run

Open the Unity project folder in Unity Hub, then press Play in the editor.
