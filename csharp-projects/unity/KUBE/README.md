# KUBE

A 3D platformer game developed using Unity and C#. This project demonstrates game development skills, including mechanics, graphics, and user experience design.

## Overview

KUBE is a 3D platformer game that allowed me to become familiar with game development software and explore various aspects of game design. The game features engaging gameplay with unique mechanics, interactive graphics, and smooth animations.

## Features

- Engaging gameplay with unique mechanics
- Interactive graphics and smooth animations
- Customizable settings for an enhanced gaming experience
- Level progression and score tracking
- 3D platforming mechanics
- Physics-based gameplay
- Particle effects and animations

## Technologies Used

### Languages & Frameworks
- **C#**: Primary programming language
- **Unity**: Game development engine

### Development Tools
- **Visual Studio**: IDE for C# scripting
- **Git / GitHub**: Version control
- **Blender**: 3D modeling and asset creation (if applicable)

## Getting Started

### Prerequisites

- Unity Hub and Unity Editor (recommended version: 2022.3 LTS)
- Visual Studio or Visual Studio Code
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/melih0132/PROJECTS.git
```

2. Navigate to the KUBE project directory:
```bash
cd csharp-projects/unity/KUBE
```

3. Open the project in Unity Hub:
   - Launch Unity Hub
   - Click "Add" and select the KUBE folder
   - Open the project with the recommended Unity version

4. Open the main scene:
   - Navigate to the Scenes folder in the Project window
   - Double-click the main scene file

5. Press Play in the Unity Editor to run the game
