# Unity Projects

This folder contains Unity game development projects, covering a wide range of games and interactive applications built with the Unity game engine. These projects demonstrate my proficiency in Unity development, C# scripting, and game design.

## Projects Included

### 1. [KUBE](KUBE)
A 3D platformer game featuring engaging gameplay and unique levels.

- 3D platforming mechanics
- Physics-based gameplay
- Level design and progression
- Particle effects and animations

**Technologies**: Unity, C#, Blender

## Technologies Used

### Languages & Frameworks
- **C#**: Primary programming language for Unity scripting
- **Unity**: Game development engine

### 3D Modeling & Assets
- **Blender**: 3D modeling and asset creation

### Development Tools
- **Unity Hub / Unity Editor**: Game development environment
- **Visual Studio**: IDE for C# scripting
- **Git / GitHub**: Version control

## Getting Started

Each project has its own README with detailed instructions. To explore a project:

1. Navigate to the project directory
2. Read the project's README.md for specific setup instructions
3. Follow the installation and configuration steps
4. Run the project according to its documentation

### Prerequisites

- Unity Hub and Unity Editor (recommended version: 2022.3 LTS)
- Visual Studio or Visual Studio Code
- Git

### Quick Start

1. Install Unity Hub and Unity Editor
2. Clone the repository
3. Open the project in Unity Hub
4. Open the main scene in the Scenes folder
5. Press Play in the Unity Editor

Feel free to explore the repositories for more detailed information on each project!
