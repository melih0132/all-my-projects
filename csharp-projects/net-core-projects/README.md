# .NET Core Projects

ASP.NET Core APIs, WinUI clients, and console EF samples.

## Overview

Coursework covering REST services, currency conversion clients, and film rating UIs on PostgreSQL.

## Stack

- C#, ASP.NET Core, Entity Framework Core
- WinUI 3, XAML
- PostgreSQL, Swagger
- xUnit / MSTest

## Layout

```
net-core-projects/
├── APIfilms/
├── ApiRestAvecEtat/
├── ClientConvertisseur/
├── FilmRatingsApp/
├── TP3console/
└── WSConvertisseur/
```

## Run

Open a child solution in Visual Studio and follow that project README.
