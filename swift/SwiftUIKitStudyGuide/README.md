# SwiftUIKitStudyGuide

English study notes for advanced Swift and UIKit topics.

## Overview

SwiftUIKitStudyGuide is a documentation-only leaf: a single README used as a revision sheet. It summarizes protocols, closures, Auto Layout, navigation, ARC, view controller lifecycle, collection views, GCD, generics, and error handling for UIKit work.

Use it as a checklist before interviews or exams; there is no Xcode project in this folder.

## Features

- Protocol and delegate review points
- Closure capture and escaping notes
- Auto Layout priorities and stack views
- Navigation and data passing patterns
- ARC, GCD, and UI threading rules
- Collection view and generics reminders

## Stack

- Markdown study guide
- Swift / UIKit concepts (no build target)

SwiftUIKitStudyGuide/

No build. Open `README.md` in an editor or Markdown preview.
