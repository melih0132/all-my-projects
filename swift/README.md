# Swift Projects

This folder contains my Swift and iOS development projects, covering a wide range of iOS applications built with Swift and UIKit. These projects demonstrate my proficiency in iOS development, UIKit framework, and various iOS technologies.

## Projects Included

### 1. [DocumentApp](DocumentApp)
iOS application for managing and browsing documents with UITableView, file system access, and image preview capabilities.

- Document browsing from application bundle
- UITableView implementation
- Image preview using Quick Look framework
- File system access

**Technologies**: Swift, UIKit, Quick Look, Foundation

### 2. [PokemonTrainerManager](PokemonTrainerManager)
Complete iOS application for managing Pokémon trainers, their teams, badges, and progression using UIKit, UITableView, navigation controllers, and JSON data loading.

- List of trainers displayed in a UITableView with custom cells
- Detailed trainer view showing Pokémon teams, badges, and statistics
- Pokémon detail view with delegation pattern
- JSON data loading from Bundle
- Navigation between views using UINavigationController
- Quick Look preview for badges and trainer cards

**Technologies**: Swift, UIKit, JSON, Codable, MVC Architecture

### 3. [SwiftPlaygrounds](SwiftPlaygrounds)
Swift fundamentals exercises and practice code using Xcode Playgrounds, covering basic to advanced Swift concepts.

- Swift syntax and basic types
- Control flow and functions
- Collections (Arrays, Dictionaries, Sets)
- Optionals and error handling
- Object-oriented programming concepts

**Technologies**: Swift, Xcode Playgrounds

### 4. [SwiftUIKitStudyGuide](SwiftUIKitStudyGuide)
Comprehensive study guide and reference material for Swift and UIKit, including advanced concepts, best practices, and QCM preparation.

- Swift fundamentals and advanced concepts
- UIKit architecture and components
- Design patterns and best practices
- Memory management (ARC)
- Auto Layout and constraints
- Table views and collection views
- Navigation and presentation

**Technologies**: Swift, UIKit, Documentation

### 5. [PokemonProjectGuides](PokemonProjectGuides)
Development guides and documentation for the Pokémon Trainer Manager project.

- Detailed specifications
- Implementation guides
- Project requirements

**Technologies**: Markdown, Documentation

## Technologies Used

### Languages & Frameworks
- **Swift**: Primary programming language
- **UIKit**: User interface framework for building iOS applications
- **Foundation**: Core functionality framework for Swift and Objective-C
- **Quick Look**: Framework for previewing documents and media files

### iOS Development
- **Xcode**: Integrated development environment for macOS
- **Interface Builder**: Visual design tool for creating user interfaces
- **Playgrounds**: Interactive Swift development environment

### Patterns & Architecture
- **MVC (Model-View-Controller)**: Architectural pattern for organizing code
- **Delegate Pattern**: Communication pattern between objects
- **Codable Protocol**: Swift's encoding and decoding mechanism

### Data Management
- **JSON Parsing**: Loading and parsing JSON data from Bundle
- **File System Access**: Reading files from application bundle
- **Bundle Resources**: Managing application assets and data files

### Development Tools
- **Git / GitHub**: Version control
- **Xcode Instruments**: Performance analysis tools
