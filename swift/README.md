# SWIFT PROJECTS

Welcome to my PROJECTS repository! This repository serves as a curated collection of my development projects, each housed in its own directory. These projects cover a wide range of domains, technologies, and complexity levels, showcasing my skills and interests in iOS development with Swift and UIKit.

## Projects

**[DocumentApp](./DocumentApp)** : iOS application for managing and browsing documents with UITableView, file system access, and image preview capabilities

**[PokemonTrainerManager](./PokemonTrainerManager)** : Complete iOS application for managing Pokémon trainers, their teams, badges, and progression using UIKit, UITableView, navigation controllers, and JSON data loading

**[SwiftPlaygrounds](./SwiftPlaygrounds)** : Swift fundamentals exercises and practice code using Xcode Playgrounds, covering basic to advanced Swift concepts

**[SwiftUIKitStudyGuide](./SwiftUIKitStudyGuide)** : Comprehensive study guide and reference material for Swift and UIKit, including advanced concepts, best practices, and QCM preparation

**[PokemonProjectGuides](./PokemonProjectGuides)** : Development guides and documentation for the Pokémon Trainer Manager project

## Getting Started

To explore a project:

1. Navigate to the desired project directory
2. Read the project's README.md for specific instructions
3. Open the `.xcodeproj` file in Xcode
4. Follow the setup and installation steps
5. Run the project according to its documentation

## Project Details

### [DocumentApp](./DocumentApp)

iOS application demonstrating document management capabilities. Features include browsing files from the application bundle, displaying document information in a UITableView, and previewing images using Quick Look framework. The application showcases UIKit fundamentals, file system access, and table view implementation.

### [PokemonTrainerManager](./PokemonTrainerManager)

Complete iOS application for managing Pokémon trainers with a full-featured interface. The application includes:
- List of trainers displayed in a UITableView with custom cells
- Detailed trainer view showing Pokémon teams, badges, and statistics
- Pokémon detail view with delegation pattern
- JSON data loading from Bundle
- Navigation between views using UINavigationController
- Quick Look preview for badges and trainer cards

This project demonstrates advanced UIKit concepts including MVC architecture, delegate pattern, JSON parsing with Codable, and complex navigation flows.

### [SwiftPlaygrounds](./SwiftPlaygrounds)

Collection of Swift playground exercises covering fundamental programming concepts. These exercises serve as learning materials and practice code for:
- Swift syntax and basic types
- Control flow and functions
- Collections (Arrays, Dictionaries, Sets)
- Optionals and error handling
- Object-oriented programming concepts

### [SwiftUIKitStudyGuide](./SwiftUIKitStudyGuide)

Comprehensive study guide covering Swift and UIKit topics from basic to advanced levels. The guide includes:
- Swift fundamentals and advanced concepts
- UIKit architecture and components
- Design patterns and best practices
- Memory management (ARC)
- Auto Layout and constraints
- Table views and collection views
- Navigation and presentation
- QCM preparation materials

### [PokemonProjectGuides](./PokemonProjectGuides)

Development documentation and guides for the Pokémon Trainer Manager project. Includes detailed specifications, implementation guides, and project requirements.
