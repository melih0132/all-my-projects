# SwiftPlaygrounds

Collection of Swift playground exercises and a bonus playground.

## Overview

SwiftPlaygrounds holds numbered exercise playgrounds (Exo1 through Exo4 parts) plus Bonus.playground. They are used for Swift language practice outside a full app target.

Open any `.playground` in Xcode to run pages and inspect results in the sidebar.

## Features

- Exo1 to Exo3 standalone playgrounds
- Exo4 split into three parts
- Bonus playground
- Runs in Xcode Playgrounds
- No app target required

## Stack

- Swift
- Xcode Playgrounds
