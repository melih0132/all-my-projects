# Python Projects

Applications, utilities, and academic exercises in Python.

## Overview

Desktop apps (Tkinter), CLI utilities, IoT/MQTT and RL samples, plus algorithms, cryptography, ML, optimisation, and MongoDB time-series labs.

## Stack

- Python 3
- Tkinter, SQLite
- NumPy, Matplotlib
- MQTT, MongoDB drivers
- OpenAI API (file-renamer)
