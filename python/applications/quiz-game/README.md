# Quiz Game

Terminal quiz that loads programming questions from JSON.

## Overview

CLI multiple-choice game with scores, high scores, and basic stats persisted on disk.

## Features

- Multiple-choice questions
- Score and high-score tracking
- Average score and timing stats
- JSON data source

## Stack

- Python 3
- JSON file I/O
- Standard library only

## Layout

```
quiz-game/
├── quiz_game.py
└── quiz_data.json
```

## Run

```bash
cd python/applications/quiz-game
python quiz_game.py
```
