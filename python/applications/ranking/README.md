# Ranking

Tkinter app to create and manage item rankings on SQLite.

## Overview

Local desktop tool for CRUD rankings, CSV export, and database backups without a remote server.

## Features

- Create, edit, delete rankings
- Item management per ranking
- Input validation
- SQLite persistence
- CSV export and DB backup

## Stack

- Python 3
- Tkinter
- SQLite

## Layout

```
ranking/
├── ranking.py
└── README.md
```

## Run

```bash
cd python/applications/ranking
python ranking.py
```
