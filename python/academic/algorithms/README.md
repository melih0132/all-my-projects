# Algorithms

Academic exercises on data structures, recursion, fractals, and image/string processing.

## Overview

Standalone Python scripts covering linked lists, trees, Hanoi, Koch snowflakes, and basic image work.

## Features

- Linked lists and trees
- Recursive algorithms (Hanoi, traversals)
- Fractal generation
- Image and string processing helpers

## Stack

- Python 3
- NumPy / Matplotlib where used for graphics

## Layout

```
algorithms/
├── linked list / tree scripts
├── recursion and Hanoi scripts
└── fractal / image scripts
```

## Run

```bash
cd python/academic/algorithms
python <script>.py
```
