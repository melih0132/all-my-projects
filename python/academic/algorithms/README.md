# Algorithms

This directory contains algorithm implementations and exercises from academic coursework.

## Contents

### Data Structures
- **04_linkedList.py**: Linked list implementation
- **05_tree.py**: Tree data structure implementation

### Recursive Algorithms
- **01_hanoi.py**: Tower of Hanoi problem
- **06_spoil_hanoi.py**: Hanoi problem solution
- **recursions.py**: Various recursive algorithm examples
- **tree.py**: Tree traversal algorithms

### Fractals and Graphics
- **02_fract.py**: Fractal generation
- **flocon_koch.py**: Koch snowflake fractal
- **paint.py**: Painting/drawing application

### Image Processing
- **05_image.py**: Image manipulation and processing

### String Processing
- **02_asciiart.py**: ASCII art generation
- **ascii_art.py**: ASCII art utilities

### Miscellaneous
- **01_mystery.py**: Mystery algorithm
- **01_random.py**: Random number generation examples
- **02_bases.py**: Base conversion algorithms
- **03_poo.py**: Object-oriented programming examples
- **03_simple.py**: Simple algorithm examples
- **04_list-dic.py**: List and dictionary operations
- **defi.py**: Challenge/problem solving
- **ex1_v1.py, ex1_v2.py**: Exercise 1 variations
- **ex2.py**: Exercise 2
- **exo1.py, exo2.py, exo3.py**: Additional exercises
- **oups.py**: Error handling examples
- **pipotron.py**: Pipotron generator
- **tirages_in.py, tirages_sans_in.py**: Drawing/selection algorithms

## Technologies

- Python 3.x
- Standard library

## Usage

Each script is self-contained and can be run independently:

```bash
python script_name.py
```
