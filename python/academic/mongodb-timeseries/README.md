# MongoDB Time-Series

Python ingestion scripts and aggregation query notes for MongoDB time-series labs.

## Overview

Local-only credentials via placeholders in `script_python/conf/`.

## Stack

- Python 3, MongoDB

## Layout

```
mongodb-timeseries/
├── script_python/
└── requetes_aggregation.js
```

## Run

```bash
# edit conf placeholders, then:
cd script_python
python timeseries_sensors.py
```
