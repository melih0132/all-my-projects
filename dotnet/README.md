# .NET

Desktop, API, and Unity work in C# / .NET.

## Overview

WPF apps with and without databases, ASP.NET / WinUI samples, and Unity games.

## Stack

- C#, .NET, ASP.NET Core, Entity Framework
- WPF, WinUI 3
- PostgreSQL
- Unity

## Layout

```
dotnet/
├── with-db/       → DB-backed WPF (dortan-app)
├── without-db/    → Console and WPF (evit-shuriken)
├── net-core/      → REST APIs, WinUI, converters
└── unity/         → KUBE
```

## Run

Open a child folder and follow its README.
