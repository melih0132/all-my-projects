# .NET Without Database

Console and WPF apps without persistent storage.

## Overview

Small learning projects focused on C#, XAML, and desktop UX.

## Stack

- C#, .NET
- WPF, XAML
- Visual Studio

## Layout

```
without-db/
├── csharp/              → Console apps
└── wpf/
    └── evit-shuriken/   → WPF action game
```

## Run

Open a child folder and follow its README.
