# **PROJECTS**

Welcome to my **PROJECTS** repository! This repository serves as a curated collection of my development projects, each housed in its own directory. These projects cover a wide range of domains, technologies, and complexity levels, showcasing my skills and interests in software development.

## **Project Categories**

### 1. **[Big Projects](big-projects)**
   - A collection of large-scale projects demonstrating advanced functionalities and architectures.
   - Projects:
     - **[lpo](big-projects/lpo)**: Bird counting data management system with PostgreSQL and Power BI

### 2. **[C# Projects](csharp-projects)**
   - Projects developed using .NET and C#, including Windows Presentation Foundation (WPF) applications, backend services, and modern .NET Core applications.
   - Structure:

     - **[.net-core-projects](csharp-projects/.net-core-projects)**: Modern .NET Core applications (REST APIs, WinUI 3)
     - **[unity](csharp-projects/unity)**: Unity game development projects
   - Features:
     - WPF applications with modern UI
     - REST APIs and web services
     - WinUI 3 desktop applications
     - Database integration
     - Unit testing
     - Game development
   - Technologies: .NET Core, C#, WPF, WinUI 3, ASP.NET Core, Entity Framework, Unity

## Getting Started

To explore any project:

1. Navigate to the desired project directory
2. Read the project's README.md for specific instructions
3. Follow the setup and installation steps
4. Run the project according to its documentation

Each project directory contains its own README with detailed information about:
- Installation requirements
- Setup instructions
- Usage examples
- Technologies used
- Project structure

Feel free to explore the repositories, and don't hesitate to reach out if you have any questions or need further information!
