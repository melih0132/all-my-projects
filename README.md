# Projects

Curated collection of academic and personal software projects.

## Overview

Work is grouped by domain: showcase apps, .NET, Docker labs, mobile, Python, and web.

## Stack

- C#, Python, PHP, JavaScript, TypeScript, Dart, Swift, Kotlin
- .NET, Laravel, React, Vue, Next.js, Flutter, Unity, Phaser
- PostgreSQL, MySQL, SQLite, Power BI
- Docker, Docker Compose

## Layout

```
├── docker/      → Container labs (basics, compose, projects)
├── dotnet/      → WPF, ASP.NET, WinUI, Unity
├── mobile/      → Flutter, Kotlin, Swift
├── python/      → Applications and academic exercises
├── showcase/    → Large apps (source or redirect stubs)
└── web/         → Front, back, Phaser
```

## Run

1. Open the target project folder
2. Read its README
3. Follow install and run steps there
