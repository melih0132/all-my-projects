# Web Projects

This folder contains my web development projects, covering a wide range of web applications from backend services to frontend interfaces and game development. These projects demonstrate my proficiency in web technologies, frameworks, and various web development tools.

## Projects Included

### 1. [Backend - OOP](back/poo)
Backend projects focused on Object-Oriented Programming (OOP) principles.

- Demonstrates the use of classes, objects, and OOP concepts in web development
- PHP-based backend applications
- Database integration

**Technologies**: PHP, SQL, Object-Oriented Programming

### 2. [Frontend](front)
Frontend projects including HTML, CSS, JavaScript, and modern web frameworks.

- **[azertype-website](front/azertype-website)**: Typing practice website
- **[projects](front/projects)**: Portfolio and project showcase website

**Technologies**: HTML, CSS, JavaScript

### 3. [Phaser Projects](phaser-projects)
Projects built using the Phaser framework for HTML5 game development.

- Interactive web games
- Real-time multiplayer functionality
- Game development techniques and best practices

**Technologies**: Phaser, HTML5, JavaScript, Node.js, Socket.io

## Technologies Used

### Frontend
- **HTML/CSS/JavaScript**: Core web technologies
- **Phaser**: HTML5 game development framework
- **Responsive Design**: Mobile-first approach

### Backend
- **PHP**: Server-side scripting language
- **Node.js**: JavaScript runtime environment
- **Express.js**: Web application framework

### Real-time Communication
- **Socket.io**: Real-time bidirectional communication
- **WebSockets**: Persistent connections for live updates

### Databases
- **SQL**: Relational database queries
- **MySQL/PostgreSQL**: Database management systems

### Development Tools
- **Git / GitHub**: Version control
- **npm**: Package manager for Node.js
- **Webpack / Vite**: Build tools and bundlers
