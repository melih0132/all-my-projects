# Web Projects

PHP back-end exercises, front-end labs, and Phaser games.

## Overview

OOP/MVC PHP samples, DOM/AJAX front labs, a typing site, and Socket.io Phaser chats.

## Stack

- PHP, MySQL, MVC
- HTML, CSS, JavaScript
- Phaser 3, Node.js, Express, Socket.io

## Layout

```
web/
├── back/poo/
├── front/
│   ├── azertype-website/
│   └── projects/
└── phaser-projects/
```

## Run

Open a child folder and follow its README (PHP server, static files, or `npm` for Phaser chats).
