# Phaser Projects

HTML5 games and realtime chat demos with Phaser and Socket.io.

## Overview

Browser games plus public/private chat servers used to practice Phaser scenes and Node realtime wiring.

## Features

- Phaser 3 scenes and sprites
- Express + Socket.io chats
- Public and private room variants

## Stack

- Phaser 3, JavaScript
- Node.js, Express, Socket.io
- Nodemon

## Layout

```
phaser-projects/
├── app/
├── chat/
├── private-chat/
└── public-chat/
```

## Run

```bash
cd web/phaser-projects/public-chat
npm install && npm start
```

Repeat for `private-chat` as needed.
