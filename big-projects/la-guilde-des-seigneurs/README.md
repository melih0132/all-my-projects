# La Guilde des Seigneurs

Symfony monorepo: JWT REST API and Twig consumer app.

## Overview

Dedicated repository for the EIP project (characters, buildings, users). This folder is a redirect only.

## Stack

- PHP, Symfony 7.4
- MySQL, Doctrine
- Lexik JWT, Nelmio OpenAPI
- Twig, Bootstrap, HttpClient
- PHPUnit
