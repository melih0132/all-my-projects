# Big Projects

Large-scale personal and academic applications.

## Overview

Full-stack and data projects. Folders marked as redirects point to dedicated GitHub repositories; others keep source in this monorepo.

## Stack

- .NET, Vue, Laravel, Node.js, React, FastAPI, Symfony
- PostgreSQL, TimescaleDB, MySQL, Power BI
- Socket.io, OpenAI, Kotlin, Z-Wave

## Layout

```
big-projects/
├── la-guilde-des-seigneurs/  → Redirect → oeoecbien/symfony-project
├── lpo/                      → Bird counting (PostgreSQL, Power BI)
├── shared-ia/                → Redirect → melih0132/shared-ia
├── smarthome-lite/           → Redirect → melih0132/smarthome-lite
├── uber-dotnet-vue/          → Redirect → melih0132/uber-clone-dotnet-vue
└── uber-laravel/             → Redirect → melih0132/uber-complete-system-laravel
```

## Run

Open a child folder and follow its README (local setup or external repository link).
