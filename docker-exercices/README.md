# Docker Exercises

Progressive Docker labs from a single Alpine image to a production-oriented todo stack.

## Overview

Coursework on images, Compose, multi-service networking, volumes, and CI. Each numbered folder is self-contained.

## Stack

- Docker, Docker Compose
- Node.js, PHP, Apache, Nginx
- MongoDB, MariaDB, PostgreSQL, Redis
- GitLab CI, GitHub Actions

## Layout

```
docker-exercices/
├── 01-basic-containers/
├── 02-sass-compilation/
├── 03-nodejs-mongodb/
├── 04-php-apache-mariadb/
├── 05-multi-service-stack/
├── 06-todo-application/
└── 07-production-todo-app/
```

## Run

```bash
cd docker-exercices/06-todo-application
docker compose up -d
```

Open any exercise README for build and access details.
