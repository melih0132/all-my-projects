# Uber Vue / .NET

Full-stack Uber-like app with ASP.NET Core and Vue.js.

## Overview

Dedicated repository for the API, Vue SPA, JWT auth, maps, and booking flows. This folder is a redirect only.

## Stack

- .NET 8, ASP.NET Core, C#
- Vue.js 3, Vuetify
- PostgreSQL, Entity Framework Core
- JWT, Leaflet, Swagger
